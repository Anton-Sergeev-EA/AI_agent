# Интеллектуальный Ассистент "Антон".
Голосовой и текстовый помощник на Python с модульной архитектурой.

## О проекте.
Интеллектуальный ассистент с текстовым интерфейсом, который умеет:
- Отвечать на приветствия.
- Выполнять математические вычисления.
- Показывать время и дату.
- Рассказывать шутки.
- Искать информацию в интернете.
- Открывать веб-сайты.
- Читать Википедию.
- Устанавливать напоминания.
- Выводить справку по командам.

## Быстрый старт.
1. Клонирование репозитория.
    git clone https://github.com/Anton-Sergeev-EA/AI_agent.git
    cd AI_agent
2. Создание виртуального окружения.
    python3 -m venv venv
    source venv/bin/activate
3. Установка зависимостей.
    pip install -r requirements.txt
4. Настройка конфигурации.
- Создайте файл .env:
    cp .env.example .env
- Отредактируйте .env:
    USE_SPEECH=False
    ASSISTANT_NAME=Антон
    OPENWEATHER_API_KEY=ваш_ключ_от_openweathermap
    NEWS_API_KEY=ваш_ключ_от_newsapi
5. Запуск ассистента.
    python run.py

##  API ключи.
Для работы некоторых функций требуются бесплатные API ключи:
## Погода (OpenWeatherMap).
1. Зарегистрируйтесь на OpenWeatherMap.
2. Получите бесплатный API ключ.
3. Добавьте в .env: OPENWEATHER_API_KEY=ваш_ключ.

# Новости (NewsAPI).
1. Зарегистрируйтесь на NewsAPI.
2. Получите бесплатный API ключ.
3. Добавьте в .env: NEWS_API_KEY=ваш_ключ.

# Зависимости.
