# Интеллектуальный Ассистент
Голосовой и текстовый помощник на Python с модульной архитектурой.

## 🚀 Быстрый старт

1. **Установка зависимостей:**
pip install -r requirements.txt

2. Настройка конфигурации:
cp .env.example .env
# Отредактируйте .env файл при необходимости

3. Запуск:
# Голосовой режим
python main.py --mode voice
# Текстовый режим (CLI)
python main.py --mode cli
# Автоопределение режима
python main.py

📁 Структура проекта
AI_agent/
├── main.py             # Главный скрипт
├── config.py           # Конфигурация
├── core/               # Ядро системы
├── skills/             # Навыки ассистента
├── utils/              # Вспомогательные функции
└── data/               # Базы данных и логи

🛠 Навыки ассистента
- Погода - "погода в Москве"
- Калькулятор - "посчитай 2+2"
- Напоминания - "напомни через 10 минут"
- Новости - "новости спорта"
- Время и дата - "который час"
- Поиск в интернете - "найди кошек"
- Открытие сайтов - "открой YouTube"
- Шутки - "расскажи шутку"
- Википедия - "википедия Python"

⚙️ Конфигурация
Отредактируйте .env файл для настройки:
env
ASSISTANT_NAME=ВашеИмя
OPENWEATHER_API_KEY=ваш_ключ  # Получите на openweathermap.org
NEWS_API_KEY=ваш_ключ        # Получите на newsapi.org

🔧 Разработка
Добавление нового навыка:
- Создайте файл в папке skills/
- Реализуйте класс с методом process(command)
- Импортируйте в core/assistant.py
- Добавьте обработчик в _init_command_patterns()

Пример навыка:
# skills/example.py
class ExampleSkill:
    def process(self, command):
        if "привет" in command:
            return "Приветствую!"
        return ""

## 🚀 **Инструкция по запуску:**

1. **Создайте папку проекта:**
mkdir intelligent-assistant
cd intelligent-assistant
2. Создайте все файлы из кода выше
3. Установите зависимости:
pip install speechrecognition pyttsx3 python-dotenv requests aiohttp wikipedia pyjokes
4. Запустите ассистента:
# Текстовый режим (рекомендуется для начала)
python main.py --mode cli
# Или голосовой режим
python main.py --mode voice

🎯 Команды для тестирования:
Текстовый режим:
> погода в Москве
> посчитай 15 * 3 + 2
> который час
> какое число
> добавь напоминание через 10 минут
> покажи напоминания
> новости спорта
> открой YouTube
> найди кошки породы мейн-кун
> расскажи шутку
> помощь
> выход

Голосовой режим:
Скажите "помощник" для активации
Затем любые команды из списка выше
Скажите "стоп" для выхода

🔑 Для получения API ключей:
1. OpenWeatherMap (погода): https://openweathermap.org/api
- Бесплатно: 60 запросов в минуту
- Добавьте ключ в .env как OPENWEATHER_API_KEY
2. NewsAPI (новости): https://newsapi.org
- Бесплатно: 100 запросов в день
- Добавьте ключ в .env как NEWS_API_KEY
